# Contributing

This repository is a mirror generated from Sterfive's internal repository, so a pull request cannot be merged here
directly. It is still the right place to be heard:

- **A question about the language or the specification**: open an issue.
- **A bug in the compiler, the editor or the web app**: open an issue with the smallest model that shows it, the
  diagnostic you got, and the one you expected.
- **A proposed change to the specification, the schema or an example**: open an issue, or a pull request as a way to
  show the change. It is applied at the source and comes back here on the next sync, with credit.

Please do not include confidential models. A namespace URI or a browse name can say more about a product than intended.
