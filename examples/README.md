# Example models

These are the models the [documentation](https://opcua-modeler.doc.sterfive.com/) walks through. They are not written
for this repository: they are copied from the documentation's sources, where every build compiles them, so an example
that did not compile would have failed that build before reaching this page.

| Model | Shows | Guide |
|---|---|---|
| [`pump.model.yaml`](./pump.model.yaml) | A DI device type, an instance, engineering units | [How to create a NodeSet2.xml file](https://opcua-modeler.doc.sterfive.com/docs/guides/create-nodeset2-xml) |
| [`quickstart.model.yaml`](./quickstart.model.yaml) | The smallest useful DI component | [Quickstart](https://opcua-modeler.doc.sterfive.com/docs/start/cli) |
| [`temperature-sensor.model.yaml`](./temperature-sensor.model.yaml) | Methods, descriptions, generated documentation | [Temperature sensor](https://opcua-modeler.doc.sterfive.com/docs/examples/temperature-sensor) |
| [`temperature-control.model.yaml`](./temperature-control.model.yaml) | A finite state machine | [State machine](https://opcua-modeler.doc.sterfive.com/docs/examples/state-machine) |
| [`robot.model.yaml`](./robot.model.yaml) | A larger model, built in steps in the guide | [Robot](https://opcua-modeler.doc.sterfive.com/docs/examples/robot) |
